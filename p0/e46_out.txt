[3] 由此直接得到的命题（rho = 0 子族，闭式，不是拟合）
  命题. 设 A = diag(A1, A2)、W = diag(W1, W2)、ran(Theta) 含于 S1、F = F1 (+) F2。
  则在噪声取块对角的子族上，对任何预算 xt >= 0：E_full(xt) = E_del(xt)，
  且下确界在 V22 -> infinity 处取到（不存在有限最优）。
  证明要点（三步，全是上表量过的量）：
  (i) Riccati 在块对角数据下不产生跨块，Pt 与 P 都块对角，故 x = tr(Theta P) 只是 V11 的函数；
  (ii) det(F Pt F^T + V) 按块相乘，det V 也是，于是 I = sum_k 0.5*log2(1 + Pt_kk/Vkk) 对 k 可加；
  (iii) 约束只含 V11，I 的第二项对 V22 单调降、下界 0，取 V22 -> infinity 得 I -> I1；
        反向不等式 E_full <= E_del 由扩族立得。证毕。
  可检验的副作用：最优 V22 应当发散，且两族曲线逐位重合
  —— E44 给的 lambda(V*) = 1e9~1e17（随 x 单调升）与"没有有限最优"完全一致，
  我当时把它读成"第二条通道几乎不测"，其实那是 (iii) 的边界行为。

[4] 相关噪声那一腿：先记我自己的错，再量真正该量的
  E44 的驻点检验是在 v2 = 1e9~1e17 那个解上做中心差分。
  但由 (iii) 那里根本没有有限最优：v2 -> infinity 时 dI/dv2 与 dx/dv2 一起趋于 0，
  所以"dI/dv2 + mu dx/dv2 = 0 成立"在边界上是恒真式，不构成证据。
