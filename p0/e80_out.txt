== E80：C 的 tier (i) 闭式：独立复算 + 假设检查 ==

[预检] 求积精度：光滑被积函数 log(1+3*0.3*x^2) 与对数奇异 log|2x| 的 n=1000/4000 漂移
    n=1000 | 光滑 +0.498036097 | 奇异 +0.063175597（精确值 (ln4-gamma-ln2)/... = +0.057965758）
    n=4000 | 光滑 +0.498036097 | 奇异 +0.059268688（精确值 (ln4-gamma-ln2)/... = +0.057965758）

[A] g = x + eps x^3, g' = 1 + 3 eps x^2（同胚）：闭式 vs C 表
    注意被积量是 g'**2（第一次跑我把 g' 直接传进去了，得到 0.1037@eps=0.3，是脚本错）

[B] g = x^2（非单射，非仿射）：闭式给什么，真相是什么
    公式值 = 1/2 log2(AM/GM) = 1/2 log2(4.0000/1.125849) = +0.9145 bit（C 的定理预言：严格正）
    闭式核对：GM 解析值 = 2 e^{-gamma} = 1.122919，数值 GM = 1.125849（奇异积分求积误差 ~1e-3）
    精确间隙 = 1/2 log2(4 / (2 e^{-gamma})) = 1/2 (1 + gamma/ln2) = +0.916373 bit（数值 0.914493）
    h(x) = 1.418939 nats, h(|x|) = 0.725791 nats  => h(x^2) - h(x) = -0.693147 nats = -1.0000 bit
    符号判定：公式 +0.9145 bit vs 真实 -1.0000 bit => **矛盾：(i) 的 "gap>=0，等号<=>仿射" 在其陈述的假设类里为假，需补 g 为同胚**

[C] 换元式 h(g(x)) = h(x) + E[log|g'|] 的前提（同胚 vs 非单射）
    eps=0.3 同胚：E log|g'| = +0.498036，换元式预测 h(g(x)) = 1.916975 nats
           构造校验：∫p_y - 1 = +2.13e-06 | E[y^2] 由 y 密度 4.150002 vs 由 x 空间 4.149988（差 +1.37e-05）
           数值 h(g(x)) = 1.916978 nats  => 与换元式差 +3.05e-06（应 <1e-4）
    g=x^2 非单射：换元式预测 h = h(x)+E log|2x| = 1.478207 nats
           真值 h(x^2) = 0.725791 nats  => 换元式高估 +0.752416 nats（= +1.0855 bit）
           => 换元式在非单射下**不成立**（漏了原像求和），C 那一行证明的前提必须写进定理。

================ 判定 ================
[A] 公式在 g=x+eps x^3 上复算到 5.1e-07 => 承认：闭式正确，"verified to six digits" 站得住
[B] g=x^2：公式给精确值 +0.916373 bit（1/2(1+gamma/ln2)），真相 -1.000000 bit => 符号相反
    => 定理陈述缺假设：需 "g 为 C^1 同胚"（换元式 h(g(x))=h(x)+E log|g'| 只在单射时成立）
    注：他们的所有数值实验都用 g=x+eps x^3（同胚），所以这是**陈述漏洞**，不是数字错误；
        但 note 里 "equality iff g is affine" 作为一般命题为假（正确说法：iff g' 几乎必然为常数）。
        非单射任务（平方、取模、量化、饱和）在实践中很常见，补上假设后 (i) 仍然完整成立。
